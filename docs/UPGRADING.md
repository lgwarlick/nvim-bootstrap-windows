# Upgrading

How to move from one major version of nvim-bootstrap-windows to the next. A major version changes the Neovim minor
version (for example 0.12 → 0.13), so plugin behavior, configuration, and key mappings may change (ADR-002).

Each major version gets its own section, newest first, covering what changed, what the user must do before and after
running the new release, and how to return to the previous release if needed. Minor and patch releases need no
upgrade guide; see CHANGELOG.md.

No upgrade guides yet: 1.0.0 is the first release.
